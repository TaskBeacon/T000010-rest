Title: Resting-state Task (EC + EO)
Construct: resting-state EEG / intrinsic neural activity

Purpose:
Show the participant-visible eyes-closed and eyes-open resting-state acquisition timeline.

Rows / conditions:
- EC: eyes-closed instruction followed by passive eyes-closed rest.
- EO: eyes-open instruction followed by fixation-based eyes-open rest.

Timeline:
- Condition instruction: 4 s; SPACE is a continue/start key outside the rest window; condition-specific instruction text and optional voice.
- Rest window: 180 s; no response keys; EC displays eyes-closed text, EO displays a central + fixation.

Notes:
- EC/EO condition sequence is generated sequentially.
- Rest windows emit condition-specific onset and offset triggers.
- No behavioral score or trial response is collected during rest.
